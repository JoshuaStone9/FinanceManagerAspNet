# Finance Manager V2 - Phase 1 Complete

Phase 1 funding configuration now includes:

- Intended contribution
- Funding frequency
- Expected funding day validation (1-31)
- Funding plan start date
- Carry missed funding forward
- Carry genuine excess into future months (default off)
- Temporary pause date and reason
- Clear distinction between paused and inactive
- Existing average monthly contribution remains read-only and independent
- Save operations return to the same pot section
- Validation errors return to the same section and display a message

The carry-excess setting is configuration only in Phase 1. Its actual allocation behaviour belongs to Phase 2.
