# Navigation Guidelines

## Information Architecture
- Dashboard is always the first destination.
- Finance contains analysis and planning pages.
- Money contains accounts, reserves and time-sensitive financial records.
- Personal contains modules that are not part of monthly financial planning.
- Utility actions remain at the bottom of the sidebar.

## Behaviour
- Highlight the active controller.
- Preserve existing route names.
- Sidebar collapse preference is stored locally in the browser.
- Below 760px, navigation becomes an off-canvas drawer.
- At intermediate widths, the sidebar defaults to icon-only mode.

## Adding a Page
Add the page to the most appropriate existing group. A new group should only be introduced when at least two related destinations exist.
