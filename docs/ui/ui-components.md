# Shared UI Components

## Introduced in Batch 1
- `fm-app-shell`: application-level sidebar/content grid.
- `fm-sidebar`: sticky primary navigation.
- `fm-nav-group`: semantic navigation grouping.
- `fm-nav-item`: links and utility buttons.
- `fm-page-container`: shared page width and padding.
- `fm-alert`: shared success and error feedback.
- `fm-dashboard-welcome`: dashboard greeting and month controls.
- `fm-dashboard-section-title`: section hierarchy.
- `fm-dashboard-grid`: 12-column dashboard layout foundation.

## Future Component Candidates
- Page header

- Empty state
- Confirmation dialog
