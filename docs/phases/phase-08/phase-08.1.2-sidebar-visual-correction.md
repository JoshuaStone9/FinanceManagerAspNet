# Phase 8.1.2 — Sidebar Visual Correction

This refinement corrects the proportions and alignment of the expanded application sidebar.

## Changes

- Reduced expanded width from 280px to 248px.
- Reduced collapsed width from 84px to 72px.
- Moved the expanded collapse control inside the brand row.
- Standardised the left alignment of navigation headings, links and footer actions.
- Reduced excessive vertical spacing and link height.
- Simplified logo, title and subtitle proportions.
- Removed horizontal movement from link hover states.
- Tightened footer spacing and Settings status styling.
- Preserved the compact collapsed state, tooltips and mobile drawer behaviour.
