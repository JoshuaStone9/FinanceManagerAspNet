# Phase 16.4 — Tasks and app switching

## Status

Proposed.

## Goal

Keep time-sensitive work globally accessible without treating it as another finance domain, and distinguish Personal Vault from Finance Manager navigation.

## Task inbox

- Display an open/due count from every finance page.
- Open a compact inbox or dedicated task view without changing domain context unnecessarily.
- Surface urgent tasks and the next recommended task on Home.
- Preserve complete, dismiss, reopen and snooze actions.
- Link generated tasks to the exact account, pot or statement that needs attention.

## App switching

- Present Finance Manager and Personal Vault as separate labelled product areas.
- Retain Personal Vault's specialist internal navigation.
- Make the switch reversible and clear on mobile and desktop.
- Do not mix Vault categories into Finance Manager primary navigation.

## Acceptance criteria

- Financial Tasks is not required as a primary sidebar domain.
- Due counts and task status are consistent between Home and the inbox.
- Task deep links resolve to actionable destinations.
- Switching to Vault clearly changes product context and switching back returns to Finance Manager.
- Authentication and read-only behaviour remain consistent across both areas.
