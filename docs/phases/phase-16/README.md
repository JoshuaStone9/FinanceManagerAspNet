# Phase 16 — Consolidated financial hubs

[All phases](../README.md) · [Roadmap](../../plans/roadmap.md)

**Status: Proposed.** Phase 16 starts only after the Phase 15 Month destination and navigation model are stable.

## Purpose

Phase 16 groups related specialist pages into coherent hubs. The work changes discovery and presentation without collapsing distinct financial concepts or forcing immediate controller rewrites.

## Programme constraints

- A hub may initially compose existing routes and controllers.
- Actual account balances and virtual pot allocations must remain clearly distinct.
- Monthly contributions and current holding valuations must not be combined.
- Shared filters and selected entities must persist when moving between hub tabs.
- Specialist routes remain compatible until replacement navigation is verified.

## Completion outcome

Finance Manager has six primary destinations: Home, Month, Accounts, Pots, Plan and Insights. Settings remains a utility destination, tasks are available as a global inbox, and Personal Vault is presented as a separate product area.
